# 袁嘉明 · 个人作品集

React + Vite 单页作品集。以《咩咩幻想曲》的蓝、粉、紫为配色来源，黄色仅用于少量星星点缀。整体采用“创作档案”的视觉线索，结合渐变、平面文件夹、像素细节和清晰的编辑式排版，作品使用本人原图。

## 本地运行

安装 Node.js 20.19+ 或 22.12+，在本目录运行：

```sh
npm install
npm run dev
```

打开终端提示的地址（默认 http://127.0.0.1:5173）。

```sh
npm run build
npm run preview
```

- `src/FolderTabs.jsx`：五个文件夹分类按钮与滚动收起行为，使用 Motion 实现柔和回弹。
- `src/ArtworkViewer.jsx`：大图切换、长图上下浏览、按钮缩放、拖动、角色故事及焦点恢复。
- `src/HeroFileStack.jsx` 与 `src/home-covers.json`：首页八个系列的文件叠放与拖动切换，封面使用五份图库封面、两份头像拼图及星巴克联名方案第一页。

- `src/works.json`：5 个分类、26 个系列、292 个作品展示条目的清单，包含原分类、系列编码、分组、标题与资源路径。

系列保持原目录分类，产品设计以星巴克联名方案优先展示，原文件名和资源编码保存在清单中，访客看到的是对应画面内容的标题。同系列集中排版，风格图库进一步分为主题封面、角色图案、字体设计、纹样设计。已移除小元素和排版背景，共精简 75 张素材。角色、字体和产品卡片根据可见区域调整取景，产品缩略图统一框比例并减少外围空白。主题视觉按每张原图的比例适配边框。幽夜派对卡片与大图使用浅色背景。四季系列的 17 张图已按发型、配饰、花卉等画面特征命名，原文件名仅保存在清单中供追溯。

每张图都能点开大图，缩略图上没有额外加号。大图以适应窗口的方式展示，图片左右两侧提供大号切换按钮；支持左右方向键、Esc、关闭按钮、点击遮罩关闭及关闭后恢复焦点。首尾图片不会循环。分类栏支持左右方向键与 Home / End。联系按钮支持邮件、电话与复制邮箱。

「一些，喜欢的世界」使用蓝、粉、紫配色的小文件夹分类按钮，带编号页签和纸张叠放，文件夹内仅保留分类名称与系列数量。切换时文件夹柔和回弹、内容淡入；从系列深处切换时平滑返回分类入口。尊重系统的减少动态效果设置。

首页以右侧插画为主要视觉，约占内容区三分之二；个人介绍以蓝粉渐变衬托白色纸张，照片和标签使用蓝、粉、紫的适量点缀。个人介绍的四张数据卡已移除，简介下方直接衔接重点项目。能力区采用浅蓝紫背景和白色卡片。黄色仅用于小按钮、编号和局部点缀。界面统一使用微软雅黑、苹方等现代无衬线字体。

首页八个系列做成可翻阅的文件叠放：咩咩幻想曲、幽夜派对、星巴克联名方案、库洛米系列、山野奇遇、粉色漫游、星辰汇、米奇系列。头像系列各用六张头像拼成封面。拖动越过一定距离即切换，无需放开鼠标；点击封面本身不会跳转，只有右下角「打开这个世界」进入对应系列。八个文件夹尺寸一致，展示框统一为 1.65:1，裁剪位置保留人物与标题；仅露出后面两张文件的边缘，错位幅度固定，不随翻阅累积。另有前后按钮、封面选择点和键盘方向键；自动切换到对应作品分类。基于用户提供的 React Bits Stack 思路改写，使用轻微平面旋转和柔和回弹。首页、模块标题、个人介绍、作品卡片与能力卡片使用统一的上移淡入，进入视野时只播放一次；小星星轻轻浮动。系统开启减少动态效果时关闭装饰动画与入场位移。

「了不起的先生们」的 14 款盲盒均有角色介绍，点击图片后在图片旁显示，切换时文案同步更新；小屏上介绍放在图片下方。7 款使用用户提供的 Excel 文案，另 7 款以同样的简短叙述语气补写。对应文案保存在 `src/works.json` 的 `description` 中，`descriptionSource` 区分原文和补写。

背景落雪保持轻柔、纯白，画布不接收鼠标事件；星星、翻页箭头与鼠标保留统一像素细节。当前落雪使用轻量 Canvas，不加载 Three.js；落雪模块延后加载，避免阻塞首页主体。

上级目录的「袁嘉明-作品集预览.html」为早期版本的自包含离线预览。本次补充更新 portfolio-site 源码及 dist，查看最新内容请使用本地预览或重新部署 dist。源码运行时使用缩略图、懒加载和点击后才加载大图。

文案依据提供的简历精简；作品仅用于个人作品展示，相关 IP 权利属于原权利人。此版本为本地基础预览，未发布到公网。


## 作品目录与连续浏览

首页显示五个分类的快捷入口，作品区以大文件夹展示分类名、系列数量与作品数量。五类作品在同一页按风格图库、数字藏品头像、产品设计、原创 IP、其他作品依次展示，下滑即可浏览全部 26 个系列、292 张作品。原来的「浏览下个文件夹」整块提示区已移除。

分享网站首页请使用 https://portfolio-site-7f3.pages.dev/ 。`#series-2-1` 是米奇系列的直达链接；`#category-1` 到 `#category-5` 是五个分类的页内锚点。点击文件夹会跳转到相应内容，支持刷新与浏览器前进/后退；自然滚动会同步高亮当前分类，其他作品始终保留在页面中。首页入口与文件夹数据统一在 `src/work-categories.js` 中维护，目录样式在 `src/studio.css`。

作品目录下滑到顶部后自动收起，桌面为约 62px 高的单行导航，小屏为约 88px 高的两行导航；滚回目录时恢复完整文件夹。固定原目录占位，避免收起或展开时作品位置跳动。五个文件夹均可用 Tab 键聚焦，继续支持方向键跳转与减少动态效果设置。近距离跳转平滑滚动，远距离分类直接定位，避免快速滑过并加载途中大量图片。当前分类与目录收起均使用缓存位置判断，分类变化不重新渲染整页作品，缩略图继续在接近视口 600px 时加载。

## 图片与滚动性能优化

图库只在距离视口约 600px 时加载缩略图。128 张需要裁切的缩略图提前生成 WebP，通过普通图片的懒加载代替 SVG 内嵌图片；提供适合不同显示尺寸的版本，原始大图与 PDF 保留。首页的头像封面预合成为一张六宫格，只展示当前封面，并低优先级预热相邻两份。

移除固定导航和大图背景的实时模糊；入场动画结束后释放动画状态，仅扫描新加入的内容。滚动时使用缓存位置判断目录收起；滚动、首页拖动、查看大图和隐藏页面时暂停相关背景动画。长图不预加载相邻完整文档，拖动与滚轮更新合并到每帧一次。

本地 1280×720 首屏复核：作品资源请求从 73 个降为 4 个；这是同一预览环境中的请求数量对比，不是网速或帧率提升百分比。图片预处理脚本为 `scripts/optimize-previews.py`，普通运行和构建不需要重新执行它。

首页左右拖动分别前进和后退，达到阈值即可切换；八份文件尺寸一致，仅显示前方三层，只有“打开这个世界”链接跳转。初次只加载当前与随后两份封面。清除系列跳转中重复叠加的顶部滚动偏移。

生产构建将 React、Motion、作品数据与页面代码分开，便于缓存；白色落雪模块约 1.34 KB（gzip 约 0.74 KB），不再附带 3D 渲染库。加入本地图标与分享元信息。沿用系统中文无衬线字体，不依赖外部字体服务。
