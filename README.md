# 袁嘉明 · 个人作品集

React + Vite 单页作品集。以《咩咩幻想曲》的蓝、粉、紫、黄为配色来源，结合蓝粉渐变、方格纸、文件夹、夹板和便签，形成撞色创作手册风格。纸张和卡片使用平面描边与少量叠放，作品使用本人原图。

## 本地运行

安装 Node.js 20.19+ 或 22.12+，在本目录运行：

```sh
npm install
npm run dev
```

打开终端提示的地址（默认 http://127.0.0.1:5173）。

```sh
npm run build
npm run preview
```

## 后续修改

- `src/main.jsx`：个人文案、经历、首页和联系方式。
- `src/WorkGallery.jsx`：作品分类、系列排版、单图大图查看。
- `src/FolderTabs.jsx` 与 `src/folder-tabs.css`：四个文件夹分类按钮，使用 Motion 实现柔和回弹。
- `src/HeroFileStack.jsx` 与 `src/home-covers.json`：首页七个系列的文件叠放与拖动切换，封面来自「封面图.rar」。
- `src/useSoftReveals.js` 与 `src/motion-theme.css`：全站柔和入场动画、首页文件外观和适配规则。
- `src/PixelSnow.jsx`：基于提供的 React Bits PixelSnow 着色器，使用纯白、低密度、慢速的像素落雪。雪点以透明度淡出，保持白色；单个背景画布限制最长边 640px、30 帧，隐藏页面时暂停，减少动态效果时关闭。无 WebGL 时使用轻量 Canvas 后备实现。
- `src/PixelMarks.jsx`、`src/pixel-theme.css` 与 `src/pixel-cursors.css`：像素星星、翻页箭头及细节，四种统一配色的原生像素鼠标（普通、点击、可拖动、拖动中）。鼠标内嵌在 CSS 中，离线版同样可用。
- `src/works.json`：根据「作品收集.rar」建立的四大类、18 个系列、230 张展示图片清单。包含原分类名称、系列编码、子分组和原始文件名。
- `src/style.css` 与 `src/gallery.css`：全站与画廊的基础布局。
- `src/sketchbook.css`：撞色创作手册主题、各模块样式及适配规则。
- `public/art/collection/`：独立图片的 WebP 大图及缩略图，保留透明背景。大图最长边最大 2400px；主题视觉缩略图最长边最大 1800px，其他缩略图最大 560px；不放大原图、不裁剪作品。
- `public/art/portrait-current.webp`：用户最新提供的个人照片。
- `public/art/covers/`：五个系列的高清首页封面，在统一比例的文件窗口内裁剪展示，保留人物与标题。

版心最大约 1700px，包含全屏首页、个人介绍与经历、分类作品画廊、能力卡片和整屏联系页。

作品分类：

1. 风格图库：咩咩幻想曲、幽夜派对、山野奇遇、粉色漫游、星辰汇。
2. 数字藏品头像：米奇、库洛米、大耳狗、唐老鸭、情人节、七宗罪（AI 辅助）、四季。
3. 产品设计：盲盒设计：了不起的先生们、大娃设计：未来奇遇、美团合作玩偶。
4. 原创 IP：sugar运营视觉、桃打、设计手稿。

系列按原目录编码排序，原文件名和资源编码保存在清单中，访客看到的是对应画面内容的标题。同系列集中排版，风格图库进一步分为主题封面、角色图案、字体设计、纹样设计。已移除小元素和排版背景，共精简 75 张素材。角色、字体和产品卡片根据可见区域调整取景，产品缩略图统一框比例并减少外围空白。主题视觉按每张原图的比例适配边框。幽夜派对卡片与大图使用浅色背景。四季系列的 17 张图已按发型、配饰、花卉等画面特征命名，原文件名仅保存在清单中供追溯。

每张图都能点开大图，缩略图上没有额外加号。大图以适应窗口的方式展示，图片左右两侧提供大号切换按钮；支持左右方向键、Esc、关闭按钮、点击遮罩关闭及关闭后恢复焦点。首尾图片不会循环。分类栏支持左右方向键与 Home / End。联系按钮支持邮件、电话与复制邮箱。

「一些，喜欢的世界」使用蓝、粉、紫配色的小文件夹分类按钮，带编号页签和纸张叠放，文件夹内仅保留分类名称与系列数量。切换时文件夹柔和回弹、内容淡入；从系列深处切换时平滑返回分类入口。尊重系统的减少动态效果设置。

首页以右侧插画为主要视觉，约占内容区三分之二；个人介绍以蓝粉渐变衬托白色纸张，照片、标签及数据卡使用蓝、粉、紫的适量点缀。能力区采用浅蓝紫背景和白色卡片。黄色仅用于小按钮、编号和局部点缀。界面统一使用微软雅黑、苹方等现代无衬线字体。

首页七个系列做成可翻阅的文件叠放：五个风格图库封面，以及米奇、库洛米的六张头像拼成的封面。拖动越过一定距离即切换，无需放开鼠标；点击封面本身不会跳转，只有右下角「打开这个世界」进入对应系列。七个文件夹尺寸一致，展示框统一为 1.65:1，裁剪位置保留人物与标题；仅露出后面两张文件的边缘，错位幅度固定，不随翻阅累积。另有前后按钮、封面选择点和键盘方向键；自动切换到对应作品分类。基于用户提供的 React Bits Stack 思路改写，使用轻微平面旋转和柔和回弹。首页、模块标题、个人介绍、作品卡片与能力卡片使用统一的上移淡入，进入视野时只播放一次；小星星轻轻浮动。系统开启减少动态效果时关闭装饰动画与入场位移。

「了不起的先生们」的 14 款盲盒均有角色介绍，点击图片后在图片旁显示，切换时文案同步更新；小屏上介绍放在图片下方。7 款使用用户提供的 Excel 文案，另 7 款以同样的简短叙述语气补写。对应文案保存在 `src/works.json` 的 `description` 中，`descriptionSource` 区分原文和补写。

背景落雪保持轻柔，画布不接收鼠标事件；作品、纸张、文字及导航置于落雪层上方。星星与部分控制图标加入像素细节，主体仍保留蓝粉渐变与平面文件夹风格。落雪模块延后加载，避免阻塞首页主体；用户提供的 PixelSnow 代码及 `three` 用于落雪渲染。

上级目录的「袁嘉明-作品集预览.html」为自包含离线版，双击即可浏览所有分类、系列和单图，不需要安装依赖。作品较多，文件体积约 70MB。源码运行时使用缩略图、懒加载和点击后才加载大图。
